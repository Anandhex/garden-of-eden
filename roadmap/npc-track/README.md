# NPC track (N0–N16)

Who NPCs are, how they behave, and the RPG rules behind them. It doesn't depend on the browser game, so you can build all of it in the terminal first.


**Status:** ✅ All built (2026-10-09 to 2026-10-12).

**How it's organised:** six stages, in the order they were built; each stage is one file.

| Stage | Phases, in build order |
|---|---|
| [Stage 1: The core NPC](stage-1-the-core-npc.md) | N0 Fixes in what exists → N1 Personality traits that drive the rules → N2 Saving NPCs and the player → N3 World knowledge and non-talking NPCs |
| [Stage 2: Inner life](stage-2-inner-life.md) | N4 Character depth → N5 Memory and relationships |
| [Stage 3: Living together](stage-3-living-together.md) | N6 Daily life → N7 The social web |
| [Stage 4: Action and growth](stage-4-action-and-growth.md) | N8 Combat and health → N9 Quests, growth and story arcs → N10 Crafting and economy |
| [Stage 5: A growing town](stage-5-a-growing-town.md) | N11 Growing the cast → N12 The world director |
| [Stage 6: The wider world](stage-6-the-wider-world.md) | N13 The wider realm → N14 Travel → N15 Localities → N16 Crowds and classes |
